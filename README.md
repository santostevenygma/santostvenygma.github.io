# SANTOSTEVE JAMES — Portfolio Website

A responsive glassmorphism portfolio website built with HTML, CSS, and JavaScript.

## Preview on your computer
1. Extract the ZIP file.
2. Open the `santosteve_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

## Publish a public link with GitHub Pages (free)
1. Sign in or create an account at https://github.com/.
2. Create a new **public** repository named `santostevejames.github.io`.
3. Upload the contents of this folder (`index.html`, `style.css`, `script.js`, `assets/`, and `README.md`) to the repository root.
4. Open the repository's **Settings → Pages**. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save if needed.
5. Wait for GitHub Pages to publish. The public address should be `https://santostevejames.github.io/` if the repository name is exactly `santostevejames.github.io` and that username is available/owned by you. Otherwise use the URL GitHub Pages shows in Settings → Pages.
6. Open the published address on your phone to test it, then copy that public link into WhatsApp.
